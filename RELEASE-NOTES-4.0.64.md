# APEX 4.0.64

- Add your own notes on the device Refurb notes tab and use Save notes.
- Save through the existing asset editor, retain unsaved-change protection, and stay on the same tab after saving.
- Keep manual notes separate from imported RefurbFlow notes and record edits in asset history.
- Add a dedicated Refurb notes column to Inventory and parts-needed Excel exports. Existing costs, totals and ordered-part exclusions are retained.
- Notes alone do not add an asset to the parts-needed spreadsheet; use Inventory export for all devices.
