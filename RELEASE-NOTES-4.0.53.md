# APEX Refurb Management Studio 4.0.53

Locations, Pallets and Pallet locations now have compact table toolbars with search, counts and creation buttons. Location creation opens a focused popup with Cancel, Create and inline errors; pallet creation retains custom naming and description.

Delete actions across inventory, locations, pallets, pallet-location details and purchase orders use the same compact bin icon, hover state, keyboard focus and disabled styling. Confirmation actions retain explanatory labels alongside the same icon. Existing deletion permissions and occupied-location/pallet safeguards remain in effect.

No cloud or database changes are required for this release.
