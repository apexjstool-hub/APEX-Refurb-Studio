# APEX Refurb Management Studio 4.0.55

The pallet-location contents page now uses a compact panel with an integrated header, summary counts and aligned table actions. Empty locations show a centred empty state and a direct Move pallets here action.

Pallet and pallet-location deletion now use themed APEX confirmation dialogs with the exact name, Cancel/Delete actions, inline errors and protection against duplicate submissions. Cancellation does not delete anything. Server-side occupied-pallet/location checks remain unchanged.

No database or cloud changes are required.
